# TiffinTrack

## Smart Tiffin Meal Plan and Billing System

TiffinTrack is a web-based platform designed to help students and small local tiffin or mess providers manage meal plans, skipped meals, daily meal counts, monthly billing, and payment records in one place.

The system aims to replace informal WhatsApp messages and handwritten records with a structured and transparent digital system.
